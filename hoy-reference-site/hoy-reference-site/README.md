# Reference Studio Website

A React/Vite recreation of the supplied screen-recording reference. It uses GSAP + ScrollTrigger and Lenis.

## Run
npm install
npm run dev

## Build
npm run build

Replace the demo image URLs in `src/main.jsx` with the exact project/media assets you own or have permission to use. The layout, palette, typography scale, and motion are already structured around the reference.
